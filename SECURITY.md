# Security

Send sensitive reports to the maintainer through [GitHub private vulnerability reporting](https://github.com/IoannisManouris/rng-bot/security/advisories/new). Include the affected file and impact. Redact credentials, private identifiers and personal data. If a credential has been exposed, revoke it with its issuer.

The `main` branch is the maintenance target. This historical project has no supported release series or guaranteed response time. Coordinate disclosure with the maintainer through the private report.
